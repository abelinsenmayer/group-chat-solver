# Frontend

TypeScript/React frontend for the Group Chat Solver project using yarn for dependency management.

## Prerequisites

- Node.js 18 or higher
- [yarn](https://yarnpkg.com/) - Install with: `npm install -g yarn`

## Installation

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   yarn install
   ```

## Development

Start the development server:
```bash
   yarn dev
   ```

## Building

Build for production:
```bash
   yarn build
   ```

Preview the production build:
```bash
   yarn preview
   ```
